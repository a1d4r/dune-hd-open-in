# Приложения

[← К README](../README.md)

Что умеет каждый пункт меню «Смотреть…» и что делать, если фильм не открылся. Приложения ставятся и настраиваются отдельно; пункт появляется, только если приложение установлено.

## Общее для всех пунктов
- ID берётся из карточки Дюны. Если нужного ID (или названия — для поиска) у карточки нет, Дюна покажет сообщение.
- Поиск идёт по названию на языке интерфейса Дюны, а если его нет — по оригинальному. Год не передаётся: нужный фильм выберите в результатах. Исключение — плагины с входом `vod_search`, им передаётся больше (см. [ниже](#плагины-iptv-channel-editor)).
- Сериал открывается на странице сериала: сезон и серию приложение не получает.
- NUM, Lampa, BYLAMPA, Prisma, VoKino, LazyMedia и FreeZona при каждом запуске заменяют то, что было открыто, — экраны от прошлых запусков не копятся. Lampa и Prisma при этом загружаются заново, около секунды.

## Как вернуться в Дюну
| Приложение | Как вернуться в карточку Дюны |
|---|---|
| NUM | Back. После просмотра раздачи — три раза: список раздач, карточка NUM, карточка Дюны. |
| Lampa, Prisma | Back начинает работать только после первого нажатия любой стрелки — так эти приложения ведут себя при каждом запуске. Сразу: долгое нажатие Back → «Завершить работу». |
| VoKino | Back — VoKino откроет своё меню, — затем вниз до «Выйти из приложения» и ENTER. Так устроен сам VoKino. |
| Stremio | Back три раза (или Home). |
| Nuvio | Back ведёт на главную Nuvio, дальше — Back ещё несколько раз (или Home). |
| FreeZona | Back дважды: сначала на главный экран FreeZona, затем в карточку Дюны. |
| Filmix | Back с экрана поиска Filmix_API. |
| Плагины IPTV Channel Editor | Back из выдачи. |

## Если фильм не нашёлся
Если приложение не знает фильм, оно обычно не пишет об ошибке, а показывает что-то своё. Найдите фильм поиском в самом приложении.

| Приложение | Что видно |
|---|---|
| Lampa | бесконечная загрузка (бывает, когда в карточке Дюны ошибка в TMDB ID) |
| Prisma | пустая карточка-заготовка с серыми плашками |
| VoKino | «Не удалось загрузить данные» — изредка VoKino не знает IMDb ID фильма, который у него есть (например, «Дом Дракона») |
| FreeZona | главный экран FreeZona; так же — если нет сети |
| ALPAC | пустая карточка «Источники не найдены» |

## NUM
Каталог и поиск торрентов для Android TV от YouROK: в нём можно найти раздачу и отправить её в торрент-клиент, например в TorrServe. Открывает карточку по TMDB ID; по IMDb ID или названию NUM открыть карточку не умеет.

## Lampa
Приложение-каталог фильмов и сериалов: [github.com/lampa-app/LAMPA](https://github.com/lampa-app/LAMPA), APK — в [Releases](https://github.com/lampa-app/LAMPA/releases/latest).
- Открывает карточку по TMDB ID. По IMDb ID или названию Lampa снаружи надёжно не открыть.
- Проверено с сервером `http://lampa.mx`. Со своим сервером Lampa (например, Lampac) не проверялось.

## BYLAMPA
Неофициальный форк Lampa со своим сервером. Открывает карточку по TMDB ID, как Lampa.

## LAMPA ATV
Неофициальная сборка Lampa. Открывает карточку по TMDB ID, как Lampa.

## Prisma
Форк Lampa: [prisma.ws](https://prisma.ws), APK — в [Releases](https://github.com/Sheinices/Prisma_TV/releases/latest).
- Открывает карточку по TMDB ID: по IMDb ID или названию Prisma открывает ненадёжно.
- Проверено с сервером `http://prisma.ws`, который Prisma предлагает при первом запуске.

## VoKino
Онлайн-кинотеатр для Android TV.
- С IMDb ID сразу открывается карточка VoKino. TMDB и Кинопоиск VoKino не понимает.
- Без IMDb ID открывается поиск VoKino по названию.

## LazyMedia
LazyMedia Deluxe — приложение, которое собирает фильмы с онлайн-кинотеатров.
- Открывается только **поиск** по названию. Сразу открыть страницу фильма нельзя: у LazyMedia нет своих ID, страница фильма принадлежит одному из сайтов-источников.
- Что найдётся, зависит от включённых в LazyMedia источников и от названия: например, «Гладиатор 2» из Дюны находится хуже, чем «Гладиатор II».
- В результатах некоторых источников бывают фильмы для взрослых, даже на обычный запрос.
- Каждый запуск попадает в историю поиска LazyMedia.

## Filmix
Поиск в **Filmix_API** — плагине Дюны для Filmix от ddaaff ([тема на forum.mydune.ru](https://forum.mydune.ru/viewtopic.php?t=246)). Это не Android-приложение: Filmix_API ставится в Дюну отдельно, как и этот плагин.
- Открывается экран поиска Filmix_API по названию. IMDb, TMDB и Кинопоиск Filmix_API не знает. В результатах — до 5 фильмов.
- Дальше всё как в Filmix_API: выберите фильм и смотрите.
- Проверено без аккаунта Filmix (Filmix_API играет в 720p). Как ведёт себя PRO-аккаунт, пока не проверено — напишите в [Issues](https://github.com/a1d4r/dune-hd-open-in/issues).

## Stremio
Stremio с потоками из ваших аддонов ([stremio.com](https://www.stremio.com/)). Открывает карточку по IMDb ID. Без него — по TMDB ID, но это сработает, только если один из ваших аддонов понимает TMDB ID.

## Nuvio
[Nuvio TV](https://github.com/NuvioMedia/NuvioTV) с потоками из ваших аддонов Nuvio. Открывает фильм по IMDb ID, без него — по TMDB ID.

## FreeZona
Неофициальная сборка клиента онлайн-кинотеатра Zona, не от авторов Zona.
- Открывает фильм и сериал только по ID Кинопоиска. IMDb и TMDB FreeZona не понимает, а поиск по названию снаружи не запустить: без ID Кинопоиска Дюна покажет сообщение.
- ID Кинопоиска в каталоге Дюны есть не у всех карточек. У фильмов он обычно есть, у сериалов — чаще нет: например, у «Игры престолов» есть, а у новых «Сёгуна», «Фоллаута» и «Дома Дракона» — нет.
- Карточку FreeZona находит на сервере Zona. Если Zona этот фильм не знает или нет сети, откроется главный экран FreeZona без сообщения.

## ALPAC
Клиент онлайн-кинотеатра для Android TV. Нужен вход в аккаунт ALPAC.
- Если у карточки есть TMDB ID нужного типа (у фильма — фильма, у сериала — сериала), сразу открывается карточка ALPAC. IMDb и Кинопоиск ALPAC не понимает.
- Иначе открывается поиск ALPAC по названию.

## Flux
Медиацентр для Android TV: каталог фильмов и сериалов, торренты, свой плеер. Аккаунт не нужен.
- Открывает карточку по TMDB ID нужного типа (у фильма — фильма, у сериала — сериала). IMDb и Кинопоиск Flux не понимает.
- Поиск по названию снаружи не запустить: без такого TMDB ID Дюна покажет сообщение.

## SeasonHit
Неофициальный клиент seasonvar.ru: сериалы, свой плеер. Аккаунт не нужен.
- Открывается только **поиск** по названию. Сразу открыть страницу сериала нельзя: SeasonHit знает только свои ID seasonvar (у каждого сезона — свой), а не TMDB, IMDb или Кинопоиск.
- Поиск находит сериалы seasonvar; фильмы — чаще нет, их ищите в разделе «Фильмы» самого SeasonHit.
- Выдача открывается в мобильном интерфейсе поиска SeasonHit, а не в ТВ-интерфейсе.
- На моделях, где Дюна стоит приложением на Android TV, SeasonHit, скорее всего, не откроется (не проверено).

## Bazinga
Плагин Дюны Bazinga (`Bazinga3`, автор TrippyCat): каталог Кинопоиска, а к фильму — источники (трекеры, Jackett и другие). Это не Android-приложение: Bazinga ставится в Дюну отдельно, например из «Коллекции плагинов» Dune BackUp.
- С ID Кинопоиска сразу открывается карточка фильма или сериала в Bazinga.
- Без него открывается поиск Кинопоиска в Bazinga по названию.
- Смотреть — через «Источники» в карточке Bazinga. Какие источники есть и работают ли они, зависит от самой Bazinga и её настроек.

## Плагины IPTV Channel Editor
IPTV Channel Editor — конструктор, в котором собирают плагины Дюны для IPTV-провайдеров. Если в таком плагине есть фильмы (VOD), например в Mir Kino, у него появляется свой пункт в «Смотреть…» — с названием и иконкой плагина. Сами плагины дают провайдеры.
- Пункт открывает в плагине выдачу его поиска по названию. ID не передаются.
- Сначала войдите в аккаунт провайдера в самом плагине: без него выдачи не будет.
- Выдача пустая, хотя фильм у провайдера есть: откройте плагин один раз и повторите — у некоторых провайдеров поиск ищет только в уже загруженном списке. Пусто бывает и тогда, когда у провайдера название записано иначе, — тогда ищите в самом плагине.
- Плагин, поставленный позже, появится в меню, а удалённый пропадёт, обычно примерно за полминуты. Если нет — после выхода Дюны из режима ожидания или перезагрузки, а сразу — если открыть экран плагина «Смотреть в приложениях».
- Плагины с входом для поиска `vod_search` получают название карточки, оригинальное название, год и всю карточку фильма, а если серия выбрана через «Сезоны» карточки, — ещё номера сезона и серии. Как искать и что показать, решает сам плагин. Такой пункт может получить любой плагин Дюны, не только собранный в IPTV Channel Editor, — см. [Для разработчиков плагинов](developers.md). В проверке у такого пункта написано `vod_search`.
- Проверено с Mir Kino; с плагинами других провайдеров не проверялось.

## Каких пунктов нет и почему
- **Kino.pub (KinoWatch)** — приложение открывает фильм только по своему внутреннему номеру kino.pub. По IMDb, TMDB или названию его не открыть, поиск снаружи тоже не запустить: пункт мог бы только открыть главный экран приложения.
- **Lift** — приложение открывает фильм только по своему внутреннему номеру, а поиск снаружи не запустить: пункт мог бы только открыть главный экран приложения.
- **LostFilm.TV (`ru.twicker.lostfilmtv`)** — приложение открывает сериал только по своему внутреннему номеру LostFilm. По IMDb, TMDB, Кинопоиску или названию его не открыть, поиск снаружи тоже не запустить: пункт мог бы только открыть главный экран приложения.
- **Lampa TV 7.7.9 (`ru.twicker.lampa`, сборка «Un»)** — карточка открывается, только если прислать ссылку повторно примерно через секунду после запуска приложения. Обход хрупкий (на медленной сети откроется главная), а сама сборка больше не обновляется. Пункт Lampa работает с официальной LAMPA (`top.rootu.lampa`).
