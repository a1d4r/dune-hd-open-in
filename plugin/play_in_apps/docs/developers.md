# Для разработчиков плагинов

[← К README](../README.md)

Любой плагин Дюны может получить свой пункт в меню «Смотреть…» карточки фильма и сам искать этот фильм. Для этого нужен вход `vod_search` в манифесте; файлы шаблона IPTV Channel Editor не нужны. Пункт показывает название и иконку из `<caption>` и `<icon_url>` манифеста.

## Как объявить
Добавьте в `dune_plugin.xml` действие `vod_search`:
```xml
<public_actions>
  <action id="vod_search">
    <type>plugin_handle_user_input</type>
    <params>
      <handler_id>entry_handler</handler_id>
      <control_id>external_search</control_id>
    </params>
  </action>
</public_actions>
```

Требования:
- Имя каталога плагина — 1–40 символов `A-Z a-z 0-9 _ . -`, не с `.` или `-` в начале, без `..`. `dune_plugin.xml` — не больше 32 КБ (32768 байт).
- `<public_actions>` — без атрибутов: из узла с атрибутами `vod_search` не читается.
- `type` — только `plugin_handle_user_input`.
- `handler_id` и `control_id` — ваши, по 1–64 символа `A-Z a-z 0-9 _ . -`. `handler_id` не должен совпадать с обработчиками play_in_apps: `setup`, `check`, `filmix_api`, `bazinga`, `iptvce_…`.
- Учитывается только первое действие `vod_search` внутри `<public_actions>`.

У сборок IPTV Channel Editor `<public_actions>` решает так: узел пустой или без рабочего `vod_search` — пункта нет; узла нет вовсе (старая версия шаблона) — пункт ищет так же, как у остальных сборок IPTV Channel Editor, по одному названию.

Пункт появляется обычно примерно через полминуты после установки плагина. Если нет — после выхода Дюны из режима ожидания, перезагрузки или открытия экрана «Смотреть в приложениях». Если вход объявлен с ошибкой, [проверка](screen.md#проверка) на экране плагина покажет строку «вход vod_search не принят» и причину; у принятого входа в проверке написано `vod_search`.

## Что придёт в плагин
По нажатию пункта Дюна вызовет `handle_user_input` вашего плагина с вашими `handler_id` и `control_id`. В `$user_input` придут ещё поля:

| Поле | Что в нём |
|---|---|
| `search` | Строка JSON: `{"title":"…","original_title":"…","year":"…"}`. `title` — название карточки на языке интерфейса Дюны, `original_title` — оригинальное, `year` — год. Пустые поля не передаются; хотя бы одно из названий есть всегда. Все значения — строки, без пробелов по краям; кириллица — как `\uXXXX`, разберите `json_decode`. |
| `movie_str` | Карточка фильма от оболочки Дюны как есть, строка JSON (`json_decode`). Поля и их типы задаёт прошивка: значения могут быть не строками и `null`, любое поле может быть пустым или отсутствовать, набор полей может меняться с прошивкой. Кроме названий и года в ней есть, например, `id`, `kp_id`, `imdb_id`, `tmdb_id`, `tmdbtv_id` (ID сериала в TMDB), `series_type`, `description`, `poster_url`. Списка серий нет (у сериала вместо `seasons` — `season_numbers`), выбранных сезона и серии — тоже. |
| `season`, `episode` | Только если серия выбрана через «Сезоны» карточки: строки из цифр, оба поля вместе, номера как в каталоге Дюны. С главной карточки их нет. Нет их и для раздела «О сериале» в «Сезонах», для сезонов без номера в каталоге и для номеров меньше 1. |

Названия для поиска берите из `search`; `movie_str` — для остального, например для ID. Остальные поля `$user_input` добавляет оболочка Дюны.

Как искать — по одному названию или по обоим, открыть ли сразу карточку, если фильм один, — решает ваш плагин.

## Ответ
Ответ обработчика (папку, диалог) Дюна выполнит от имени вашего плагина. Back из вашей папки вернёт в карточку Дюны.
