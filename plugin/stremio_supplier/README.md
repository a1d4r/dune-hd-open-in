# «Открыть в Stremio» для Dune HD

**Русский** | [English](README.en.md)

Плагин для Dune HD: добавляет пункт **«Stremio»** в меню **«Смотреть…»** карточки фильма или сериала в каталоге **«Фильмы»** Дюны. Пункт открывает тот же фильм или сериал в [Stremio](https://www.stremio.com/) с потоками из ваших аддонов Stremio.

Сделан для Dune HD Pro 8K Plus, прошивка 260827_0003_r24, и Stremio для Android TV 1.11.2 (`com.stremio.one`, Google Play).

### Установка
1. Скопируйте `dune_plugin_stremio_supplier_<версия>.zip` на флешку или во внутреннюю память.
2. На Дюне откройте **«Источники»**, найдите zip и нажмите ENTER.
3. Примерно через полминуты пункт появится в меню **«Смотреть…»**, перезагрузка не нужна. Если не появился — удалите плагин и поставьте заново.

### Как работает
- Карточка открывается по IMDb ID (`stremio:///detail/movie/tt…`, `stremio:///detail/series/tt…`). Если IMDb ID у неё нет — по TMDB ID (`stremio:///detail/movie/tmdb:…`, `stremio:///detail/series/tmdb:…`); это сработает, только если один из ваших аддонов Stremio понимает TMDB ID.
- Сериал открывается на странице сериала: сезон и серию Дюна не передаёт.
- Чтобы выйти из Stremio и вернуться в карточку Дюны, нажмите Back три раза (или Home).
- Если Stremio не установлен или у карточки нет IMDb/TMDB ID, Дюна покажет сообщение.
- Плагин не ходит в сеть и ничего не запускает в фоне.

### Удаление
Удалите плагин в списке плагинов Дюны. Скрыть пункт в настройках Дюны нельзя (в **«Настройки → Приложения → Фильмы → Расширения»** показываются только плагины из Dune Store), поэтому выключить его можно только удалением плагина.
