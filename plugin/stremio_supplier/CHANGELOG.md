# Changelog

**English version**

## 0.1.0
- First version: "Open in Stremio" item with the Stremio icon in the "Play..." menu of the Movies catalog card.
- Opens the title by IMDb ID; without IMDb, by TMDB ID (needs a Stremio addon that understands TMDB IDs).
- Clear error messages when Stremio is not installed or the title has no IMDb/TMDB ID.

**Russian version**

## 0.1.0
- Первая версия: пункт «Открыть в Stremio» с иконкой Stremio в меню «Смотреть…» карточки каталога «Фильмы».
- Открывает фильм или сериал по IMDb ID, а если его нет — по TMDB ID (нужен аддон Stremio, который понимает TMDB ID).
- Понятные сообщения, если Stremio не установлен или у карточки нет IMDb/TMDB ID.
