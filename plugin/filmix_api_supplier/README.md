# «Открыть в Filmix» для Dune HD

**Русский** | [English](README.en.md)

Плагин для Dune HD: добавляет пункт **«Filmix»** в меню **«Смотреть…»** карточки фильма или сериала в каталоге **«Фильмы»** Дюны. Пункт открывает поиск этого фильма или сериала в **Filmix_API** — плагине Дюны для Filmix от ddaaff ([тема на forum.mydune.ru](https://forum.mydune.ru/viewtopic.php?t=246)). Это не Android-приложение: Filmix_API ставится в Дюну, как и этот плагин.

Сделан для Dune HD Pro 8K Plus, прошивка 260827_0003_r24, и Filmix_API 0.1.9.

### Установка
1. Установите Filmix_API (zip — в первом сообщении темы на форуме).
2. Скопируйте `dune_plugin_filmix_api_supplier_<версия>.zip` на флешку или во внутреннюю память.
3. На Дюне откройте **«Источники»**, найдите zip и нажмите ENTER.
4. Примерно через полминуты пункт появится в меню **«Смотреть…»**, перезагрузка не нужна. Если не появился — удалите плагин и поставьте заново.

### Как работает
- Открывается экран **поиска** Filmix_API по названию карточки — на языке интерфейса Дюны, а если его нет — по оригинальному. Сразу открыть страницу фильма нельзя: Filmix_API не знает IMDb, TMDB и Кинопоиск. Год в поиск не передаётся, в результатах — до 5 фильмов.
- Дальше всё как в Filmix_API: выберите фильм и смотрите. Back с экрана поиска возвращает в карточку Дюны.
- Проверено без аккаунта Filmix (Filmix_API играет в 720p). Как ведёт себя PRO-аккаунт при входе через этот пункт, пока не проверено — напишите в Issues.
- Если Filmix_API не установлен, Дюна покажет сообщение.
- Плагин не ходит в сеть и ничего не запускает в фоне: поиск делает сам Filmix_API.

### Удаление
Удалите плагин в списке плагинов Дюны. Скрыть пункт в настройках Дюны нельзя (в **«Настройки → Приложения → Фильмы → Расширения»** показываются только плагины из Dune Store), поэтому выключить его можно только удалением плагина.
