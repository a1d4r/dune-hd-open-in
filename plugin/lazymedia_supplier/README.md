# «Открыть в LazyMedia» для Dune HD

**Русский** | [English](README.en.md)

Плагин для Dune HD: добавляет пункт **«LazyMedia»** в меню **«Смотреть…»** карточки фильма или сериала в каталоге **«Фильмы»** Дюны. Пункт открывает поиск этого фильма или сериала в LazyMedia Deluxe — приложении для Android TV, которое собирает фильмы с онлайн-кинотеатров.

Сделан для Dune HD Pro 8K Plus, прошивка 260827_0003_r24, и LazyMedia Deluxe 3.467 (`com.lazycatsoftware.lmd`).

### Установка
1. Скопируйте `dune_plugin_lazymedia_supplier_<версия>.zip` на флешку или во внутреннюю память.
2. На Дюне откройте **«Источники»**, найдите zip и нажмите ENTER.
3. Примерно через полминуты пункт появится в меню **«Смотреть…»**, перезагрузка не нужна. Если не появился — удалите плагин и поставьте заново.

### Как работает
- Открывается **поиск** LazyMedia по названию карточки — на языке интерфейса Дюны, а если его нет — по оригинальному. Сразу открыть страницу фильма нельзя: у LazyMedia нет своих ID (IMDb, TMDB, Кинопоиск), страница фильма принадлежит одному из сайтов-источников.
- Нужный фильм выберите в результатах. Что найдётся, зависит от включённых в LazyMedia источников и от названия: например, «Гладиатор 2» из Дюны находится хуже, чем «Гладиатор II», а у «Игры престолов» первыми идут документальные фильмы о сериале. Год в поиск не передаётся.
- В результатах некоторых источников бывают фильмы для взрослых, даже на обычный запрос.
- Каждый запуск попадает в историю поиска LazyMedia.
- Каждый запуск заменяет то, что было открыто в LazyMedia, — экраны от прошлых запусков не копятся.
- Если LazyMedia Deluxe не установлен, Дюна покажет сообщение.
- Плагин не ходит в сеть и ничего не запускает в фоне.

### Удаление
Удалите плагин в списке плагинов Дюны. Скрыть пункт в настройках Дюны нельзя (в **«Настройки → Приложения → Фильмы → Расширения»** показываются только плагины из Dune Store), поэтому выключить его можно только удалением плагина.
