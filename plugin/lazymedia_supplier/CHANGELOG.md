# Changelog

**English version**

## 0.1.2
- Fixed "LazyMedia Deluxe is not installed" on Dune HD Media Center installed as an app on Android TV devices (e.g. Homatics).

## 0.1.1
- The menu item did not appear on older Android-based Dune models (Realtek RTD1619/RTD1395/RTD1295, Amlogic S905X3 and others, where FS_PREFIX is not set). Fixed: install the new version over the old one.

## 0.1.0
- First version: "LazyMedia" item with the LazyMedia Deluxe icon in the "Play..." menu of the Movies catalog card.
- Opens LazyMedia Deluxe search with the card's title (LazyMedia cannot open a title by ID).
- Clear error messages when LazyMedia Deluxe is not installed or the card has no title.

**Russian version**

## 0.1.2
- Исправлено «LazyMedia Deluxe не установлен» на Dune HD Media Center, установленном приложением на Android TV (например, Homatics).

## 0.1.1
- Пункт меню не появлялся на старых Android-моделях Дюны (Realtek RTD1619/RTD1395/RTD1295, Amlogic S905X3 и др., где не задан FS_PREFIX). Исправлено: установите новую версию поверх старой.

## 0.1.0
- Первая версия: пункт «LazyMedia» с иконкой LazyMedia Deluxe в меню «Смотреть…» карточки каталога «Фильмы».
- Открывает поиск LazyMedia Deluxe по названию карточки (открыть фильм по ID LazyMedia не умеет).
- Понятные сообщения, если LazyMedia Deluxe не установлен или у карточки нет названия.
