# «Открыть в VoKino» для Dune HD

**Русский** | [English](README.en.md)

Плагин для Dune HD: добавляет пункт **«VoKino»** в меню **«Смотреть…»** карточки фильма или сериала в каталоге **«Фильмы»** Дюны. Пункт открывает тот же фильм или сериал в VoKino — онлайн-кинотеатре для Android TV.

Сделан для Dune HD Pro 8K Plus, прошивка 260827_0003_r24, и VoKino 1.1.1 (`ru.vokino.web`).

### Установка
1. Скопируйте `dune_plugin_vokino_supplier_<версия>.zip` на флешку или во внутреннюю память.
2. На Дюне откройте **«Источники»**, найдите zip и нажмите ENTER.
3. Примерно через полминуты пункт появится в меню **«Смотреть…»**, перезагрузка не нужна. Если не появился — удалите плагин и поставьте заново.

### Как работает
- Если у карточки есть IMDb ID, сразу открывается карточка VoKino (`vokino://ru.vokino.web/view/tt…`). TMDB и Кинопоиск VoKino не понимает.
- Если IMDb ID нет, открывается поиск VoKino по названию карточки — на языке интерфейса Дюны, а если его нет — по оригинальному. Год поиск не учитывает — нужный фильм выберите в списке.
- Изредка VoKino не знает IMDb ID фильма, который у него есть (например, «Дом Дракона»): тогда VoKino покажет «Не удалось загрузить данные». Найдите фильм поиском в самом VoKino.
- Сериал открывается на странице сериала: сезон и серию Дюна не передаёт.
- Каждый запуск заменяет то, что было открыто в VoKino, — экраны от прошлых запусков не копятся.
- Чтобы вернуться в карточку Дюны: Back — VoKino откроет своё меню, — затем вниз до «Выйти из приложения» и ENTER. Так устроен сам VoKino.
- Если VoKino не установлен, Дюна покажет сообщение.
- Плагин не ходит в сеть и ничего не запускает в фоне.

### Удаление
Удалите плагин в списке плагинов Дюны. Скрыть пункт в настройках Дюны нельзя (в **«Настройки → Приложения → Фильмы → Расширения»** показываются только плагины из Dune Store), поэтому выключить его можно только удалением плагина.
