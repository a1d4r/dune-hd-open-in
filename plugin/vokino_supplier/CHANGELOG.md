# Changelog

**English version**

## 0.1.3
- App icon now shows on Dune HD Media Center installed as an app on Android TV (e.g. Homatics).

## 0.1.2
- Fixed "VoKino is not installed" on Dune HD Media Center installed as an app on Android TV devices (e.g. Homatics).

## 0.1.1
- The menu item did not appear on older Android-based Dune models (Realtek RTD1619/RTD1395/RTD1295, Amlogic S905X3 and others, where FS_PREFIX is not set). Fixed: install the new version over the old one.

## 0.1.0
- First version: "VoKino" item with the VoKino icon in the "Play..." menu of the Movies catalog card.
- Opens the movie or series in VoKino by IMDb ID; without one, searches VoKino by the title.
- Clear error messages when VoKino is not installed or the card has neither an IMDb ID nor a title.
