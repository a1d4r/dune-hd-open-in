# «Открыть в NUM» для Dune HD

**Русский** | [English](README.en.md)

Плагин для Dune HD: добавляет пункт **«Открыть в NUM»** в меню **«Смотреть…»** карточки фильма или сериала в каталоге **«Фильмы»** Дюны. Пункт открывает тот же фильм или сериал в NUM — каталоге и поиске торрентов для Android TV от YouROK: там можно найти раздачу и отправить её в торрент-клиент, например в TorrServe.

Сделан для Dune HD Pro 8K Plus, прошивка 260827_0003_r24, и NUM 1.0.150 (`ru.yourok.num`).

### Установка
1. Скопируйте `dune_plugin_num_supplier_<версия>.zip` на флешку или во внутреннюю память.
2. На Дюне откройте **«Источники»**, найдите zip и нажмите ENTER.
3. Примерно через полминуты пункт появится в меню **«Смотреть…»**, перезагрузка не нужна. Если не появился — удалите плагин и поставьте заново.

### Как работает
- Карточка открывается по TMDB ID (`https://www.themoviedb.org/movie/…`, `https://www.themoviedb.org/tv/…`). По IMDb ID или названию NUM открыть карточку не умеет, поэтому карточку без TMDB ID открыть нельзя.
- Сериал открывается на странице сериала: сезон и серию Дюна не передаёт.
- Каждый запуск заменяет то, что было открыто в NUM, — экраны от прошлых запусков не копятся.
- Из карточки NUM в карточку Дюны — одно нажатие Back. После просмотра раздачи — три: список раздач, карточка NUM, карточка Дюны.
- Если NUM не установлен или у карточки нет TMDB ID, Дюна покажет сообщение.
- Плагин не ходит в сеть и ничего не запускает в фоне.

### Удаление
Удалите плагин в списке плагинов Дюны. Скрыть пункт в настройках Дюны нельзя (в **«Настройки → Приложения → Фильмы → Расширения»** показываются только плагины из Dune Store), поэтому выключить его можно только удалением плагина.
