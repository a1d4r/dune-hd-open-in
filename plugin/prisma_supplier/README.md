# «Открыть в Prisma» для Dune HD

**Русский** | [English](README.en.md)

Плагин для Dune HD: добавляет пункт **«Prisma»** в меню **«Смотреть…»** карточки фильма или сериала в каталоге **«Фильмы»** Дюны. Пункт открывает тот же фильм или сериал в Prisma — приложении-каталоге фильмов и сериалов для Android TV (форк Lampa).

Сделан для Dune HD Pro 8K Plus, прошивка 260827_0003_r24, и Prisma 1.3.4 (`top.rootu.prisma`, сервер `http://prisma.ws`). Prisma: [prisma.ws](https://prisma.ws), APK — в [Releases](https://github.com/Sheinices/Prisma_TV/releases/latest).

### Установка
1. Скопируйте `dune_plugin_prisma_supplier_<версия>.zip` на флешку или во внутреннюю память.
2. На Дюне откройте **«Источники»**, найдите zip и нажмите ENTER.
3. Примерно через полминуты пункт появится в меню **«Смотреть…»**, перезагрузка не нужна. Если не появился — удалите плагин и поставьте заново.

### Как работает
- Карточка открывается по TMDB ID (`https://www.themoviedb.org/movie/…`, `https://www.themoviedb.org/tv/…`). Карточку без TMDB ID плагин не открывает: у Lampa, на которой основана Prisma, открытие по IMDb ID или названию ненадёжно.
- Сериал открывается на странице сериала: сезон и серию Дюна не передаёт.
- Каждый запуск заменяет то, что было открыто в Prisma, — экраны от прошлых запусков не копятся. Prisma при этом загружается заново, около секунды.
- Back в Prisma начинает работать только после первого нажатия любой стрелки — особенность приложения, так же ведёт себя Lampa. Сразу вернуться в карточку Дюны: долгое нажатие Back → «Завершить работу».
- Если Prisma не установлена или у карточки нет TMDB ID, Дюна покажет сообщение.
- Если такого TMDB ID в Prisma нет (бывает, когда у Дюны ошибка в ID), Prisma покажет пустую карточку-заготовку (серые плашки), а не сообщение.
- Проверено с сервером `http://prisma.ws`, который Prisma предлагает при первом запуске. С другим адресом сервера не проверялось.
- Плагин не ходит в сеть и ничего не запускает в фоне.

### Удаление
Удалите плагин в списке плагинов Дюны. Скрыть пункт в настройках Дюны нельзя (в **«Настройки → Приложения → Фильмы → Расширения»** показываются только плагины из Dune Store), поэтому выключить его можно только удалением плагина.
