# «Открыть в Lampa» для Dune HD

**Русский** | [English](README.en.md)

Плагин для Dune HD: добавляет пункт **«Lampa»** в меню **«Смотреть…»** карточки фильма или сериала в каталоге **«Фильмы»** Дюны. Пункт открывает тот же фильм или сериал в Lampa — приложении-каталоге фильмов и сериалов для Android TV.

Сделан для Dune HD Pro 8K Plus, прошивка 260827_0003_r24, и Lampa 1.13.1 (`top.rootu.lampa`, сервер `http://lampa.mx`). Lampa: [github.com/lampa-app/LAMPA](https://github.com/lampa-app/LAMPA), APK — в [Releases](https://github.com/lampa-app/LAMPA/releases/latest).

### Установка
1. Скопируйте `dune_plugin_lampa_supplier_<версия>.zip` на флешку или во внутреннюю память.
2. На Дюне откройте **«Источники»**, найдите zip и нажмите ENTER.
3. Примерно через полминуты пункт появится в меню **«Смотреть…»**, перезагрузка не нужна. Если не появился — удалите плагин и поставьте заново.

### Как работает
- Карточка открывается по TMDB ID (`https://www.themoviedb.org/movie/…`, `https://www.themoviedb.org/tv/…`). По IMDb ID или названию Lampa снаружи надёжно открыть карточку не умеет, поэтому карточку без TMDB ID открыть нельзя.
- Сериал открывается на странице сериала: сезон и серию Дюна не передаёт.
- Каждый запуск заменяет то, что было открыто в Lampa, — экраны от прошлых запусков не копятся. Lampa при этом загружается заново, около секунды.
- Если Lampa не установлена или у карточки нет TMDB ID, Дюна покажет сообщение.
- Если такого TMDB ID в Lampa нет (бывает, когда у Дюны ошибка в ID), Lampa покажет бесконечную загрузку, а не сообщение.
- Проверено с сервером `http://lampa.mx`. Со своим сервером Lampa (например, Lampac) не проверялось.
- Плагин не ходит в сеть и ничего не запускает в фоне.

### Удаление
Удалите плагин в списке плагинов Дюны. Скрыть пункт в настройках Дюны нельзя (в **«Настройки → Приложения → Фильмы → Расширения»** показываются только плагины из Dune Store), поэтому выключить его можно только удалением плагина.
