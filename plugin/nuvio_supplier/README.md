# «Открыть в Nuvio» для Dune HD

**Русский** | [English](README.en.md)

Плагин для Dune HD: добавляет пункт **«Nuvio»** в меню **«Смотреть…»** карточки фильма или сериала в каталоге **«Фильмы»** Дюны. Пункт открывает тот же фильм в [Nuvio TV](https://github.com/NuvioMedia/NuvioTV) с потоками из ваших аддонов Nuvio.

Сделан для Dune HD Pro 8K Plus, прошивка 260827_0003_r24, и Nuvio TV 1.0.0 (`com.nuvio.tv`).

### Установка
1. Скопируйте `dune_plugin_nuvio_supplier_<версия>.zip` на флешку или во внутреннюю память.
2. На Дюне откройте **«Источники»**, найдите zip и нажмите ENTER.
3. Примерно через полминуты пункт появится в меню **«Смотреть…»**, перезагрузка не нужна. Если не появился — удалите плагин и поставьте заново.

### Как работает
- Фильм открывается по IMDb ID (`nuvio://movie/tt…`, `nuvio://series/tt…`). Если IMDb ID у карточки нет — по TMDB ID (`nuvio://tmdb/movie/…`, `nuvio://tmdb/series/…`).
- Сериал открывается на странице сериала: сезон и серию Дюна не передаёт.
- Back с карточки Nuvio ведёт на главную Nuvio; чтобы выйти из Nuvio и вернуться в карточку Дюны, нажмите Back ещё несколько раз (или Home).
- Если Nuvio не установлен или у карточки нет IMDb/TMDB ID, Дюна покажет сообщение.
- Плагин не ходит в сеть и ничего не запускает в фоне.

### Удаление
Удалите плагин в списке плагинов Дюны. Скрыть пункт в настройках Дюны нельзя (в **«Настройки → Приложения → Фильмы → Расширения»** показываются только плагины из Dune Store), поэтому выключить его можно только удалением плагина.
