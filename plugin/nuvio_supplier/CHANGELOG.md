# Changelog

**English version**

## 0.2.4
- App icon now shows on Dune HD Media Center installed as an app on Android TV (e.g. Homatics).

## 0.2.3
- Fixed "Nuvio is not installed" on Dune HD Media Center installed as an app on Android TV devices (e.g. Homatics).

## 0.2.2
- The menu item did not appear on older Android-based Dune models (Realtek RTD1619/RTD1395/RTD1295, Amlogic S905X3 and others, where FS_PREFIX is not set). Fixed: install the new version over the old one.

## 0.2.1
- The menu item is now called just "Nuvio", like Kinopoisk and other apps in the "Play..." menu. The plugin keeps its name "Open in Nuvio".

## 0.2.0
- The menu item shows the Nuvio icon (taken from the icon cache Dune builds for installed apps).

## 0.1.1
- Russian error text for a title without IMDb/TMDB ID no longer says "film" for series.

## 0.1.0
- First version: "Open in Nuvio" item in the "Play..." menu of the Movies catalog card.
- Opens the title by IMDb ID; without IMDb, by TMDB ID.
- Clear error messages when Nuvio is not installed or the title has no IMDb/TMDB ID.

**Russian version**

## 0.2.4
- Иконка приложения теперь показывается в Dune HD Media Center, установленном приложением на Android TV (например, Homatics).

## 0.2.3
- Исправлено «Nuvio не установлен» на Dune HD Media Center, установленном приложением на Android TV (например, Homatics).

## 0.2.2
- Пункт меню не появлялся на старых Android-моделях Дюны (Realtek RTD1619/RTD1395/RTD1295, Amlogic S905X3 и др., где не задан FS_PREFIX). Исправлено: установите новую версию поверх старой.

## 0.2.1
- Пункт меню теперь называется просто «Nuvio», как «Kinopoisk» и другие приложения в меню «Смотреть…». Название плагина осталось «Открыть в Nuvio».

## 0.2.0
- У пункта меню иконка Nuvio (из кэша иконок, который Дюна строит для установленных приложений).

## 0.1.1
- Текст ошибки для карточки без IMDb/TMDB ID больше не называет сериал «фильмом».

## 0.1.0
- Первая версия: пункт «Открыть в Nuvio» в меню «Смотреть…» карточки каталога «Фильмы».
- Открывает фильм или сериал по IMDb ID, а если его нет — по TMDB ID.
- Понятные сообщения, если Nuvio не установлен или у фильма нет IMDb/TMDB ID.
