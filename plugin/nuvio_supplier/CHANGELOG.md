# Changelog

**English version**

## 0.2.0
- The menu item shows the Nuvio icon (taken from the icon cache Dune builds for installed apps).

## 0.1.1
- Russian error text for a title without IMDb/TMDB ID no longer says "film" for series.

## 0.1.0
- First version: "Open in Nuvio" item in the "Play..." menu of the Movies catalog card.
- Opens the title by IMDb ID; without IMDb, by TMDB ID.
- Clear error messages when Nuvio is not installed or the title has no IMDb/TMDB ID.

**Russian version**

## 0.1.1

- Понятные сообщения, если Nuvio не установлен или у фильма нет IMDb/TMDB ID.
